## Что подтверждено источниками

В OEM model97 `VoiceAirConditionListener.onAirConditionChanged` поле
`airCirculationMode` имеет три значения: 0 — внешний воздух, 1 — рециркуляция,
2 — AUTO. Прежнее преобразование принимало только 0/1, поэтому AUTO становился
неизвестным значением. CAF при этом не получал отдельного признака автоматического
режима и мог сохранять старый значок.

В журнале приложения после выбора рециркуляции есть неподтверждённый результат
11:56:39.912 (`readback=null`), а позднее — переходы false → true → null.
Сам журнал приложения не показывает, какой значок в этот момент рисовал iPhone.

Заголовки CAF подтверждают независимые характеристики:

- [CAFRecirculation.h](https://github.com/qingralf/iOS18-Runtime-Headers/blob/cfdd406d3a0bbac8473571dda5482e155b1cc402/PrivateFrameworks/CarAccessoryFramework.framework/CAFRecirculation.h): writable `on`, read-only `autoMode`.
- [CAFSeatFan.h](https://github.com/qingralf/iOS18-Runtime-Headers/blob/cfdd406d3a0bbac8473571dda5482e155b1cc402/PrivateFrameworks/CarAccessoryFramework.framework/CAFSeatFan.h): `fanLevel` типа UInt8, диапазон, отдельный `on`, необязательный `autoMode` и VehicleLayoutKey.
- [CAFSeatFanObservable](https://github.com/qingralf/iOS18-Runtime-Headers/blob/cfdd406d3a0bbac8473571dda5482e155b1cc402/PrivateFrameworks/CAFCombine.framework/CAFCombine.CAFSeatFanObservable.h): отдельные наблюдатели fanLevel, on и autoMode.

Существующий тип SeatFan и формат UInt8 были выбраны правильно. В журнале iPhone
подписан на уровень и включение обоих сидений. Повторные запросы уровня 3
подтверждались OEM и отправлялись обратно в CAF. Поэтому причина отображения
вентиляции не сводится к отсутствующей подписке или неправильному типу числа.
Достаточность изменений ниже ещё требует проверки на экране.

## Изменения

Рециркуляция публикует On (iid 71) и AutoMode (iid 72):

| OEM режим | On | AutoMode |
| --- | --- | --- |
| 0, внешний воздух | false | false |
| 1, внутренняя рециркуляция | true | false |
| 2, AUTO | false | true |
| Неизвестный | недоступно | недоступно |

On в AUTO означает отсутствие ручного запроса рециркуляции. Положение заслонки
из этого не выводится: смысл отдельного OEM поля airCirculationStatus не установлен.
Для подтверждения ручной команды сравнивается исходный режим 0/1; AUTO никогда
не считается успешным выполнением ручного выключения. После записи сразу
обновляются и On, и AutoMode из одного обратного чтения TX30.
Сохраняются прежние ограничения: максимум два импульса, второй только после
подтверждённого перехода режима.

Для вентиляции выбранная ступень отделена от включения:

- Включение определяется штатным переключателем, выбранная ступень — отдельным
  полем COMMAND_LEFT/RIGHT. Сохранённый уровень при выключенном сиденье не
  выдаётся за активную вентиляцию.
- SeatFan объявляет выбранную ступень 1…3 и отдельный On. При выключении ступень
  сохраняется; если OEM не сохранил допустимого выбора, используется минимум 1
  при On=false. Неизвестное или устаревшее состояние включения остаётся недоступным.
- On=true восстанавливает выбранную ступень. On=false задаёт OEM уровень 0.
  Нулевая запись непосредственно в FanLevel отклоняется как выход за его новый диапазон.
- После подтверждённой записи отправляются и уровень, и On, включая неизменившиеся
  значения. Это даёт двум наблюдателям iPhone согласованное подтверждение.
- Добавлен read-only AutoMode=false для ручного управления вентиляцией сидений.
- Повторный запрос уровня 3 остаётся абсолютной командой 3. Он не превращается
  в произвольное переключение 3→2: повтор запроса может быть повтором доставки.

## Проверки

180 профильных тестов shared прошли: Ultra, UI Sync, iAP2, /info, AirPlaySession,
CarPlayMediaEngine и преобразование вентилятора. Пять новых тестов проверяют три
режима рециркуляции, AutoMode, независимость выбранной ступени от On, подтверждение
обоих значений, последовательность явных запросов 3→2→1→выкл→вкл и устаревший снимок.
Это проверка протокола; она не доказывает, что iPhone начнёт посылать ступени 2 и 1.

Пять Java-тестов VoyahComfortValuesTest отдельно скомпилированы и прошли JUnit,
включая сохранение выбранного уровня 2 при выключенной вентиляции.

Полная команда CI из AGENTS.md выполнена с `--offline --continue` и дополнительной
`:automotive:assembleDebug`. Сохраняются три прежние причины неуспеха:

- mobile: minSdk 25 меньше 28 у common;
- common: ошибки компиляции существующих посторонних unit-тестов; добавленный
  VoyahHvacSchemaTest через этот общий набор не выполнен;
- shared: 1652 теста, 78 падений, 0 ошибок. Идентификаторы всех 78 точно совпали
  с сохранённым списком `build/info-latency-20261024/full-shared-failures.txt`.

home unit tests, home/maphost lint и assemble прошли; automotive APK собран.
Подпись APK v2 проверена. Новые настройки и изменения раскладки Android не добавлялись.
