## Почему в приложении «Автомобиль» видна только громкость

Настройки производителя в VoyahClimateAccessory.automakerSettings() описывают
только раздел VoyahPlay со строкой версии. Дополнительно объявлен аудиосервис
с изменяемой громкостью. Обновляемые строки давления, пробега и запаса хода
в этом дереве настроек не описаны.

Сама телеметрия объявлена отдельными CAF-аксессуарами Tires, Fuel и TripComputer
в VoyahVehicleAccessories.kt. iPhone подписался на неё и получил значения.
Последние подтверждённые CAF TX в этом опыте:

| Данные | IID | Переданное значение |
| --- | --- | --- |
| Давление ПЛ / ПП / ЗЛ / ЗП | 2050 / 2055 / 2060 / 2065 | 250 / 250 / 260 / 270 кПа |
| Общий запас хода | 1794 | 568 км |
| Пробег | 1798 | 6081 км |
| Уровень топлива | 1538 | 100% |

Это доказательство передачи значений адаптера, а не отдельная калибровка всех
OEM полей по приборке. Топливный запас хода 1541/1542 намеренно недоступен,
1543=true; общий запас хода передаётся отдельно и не скрыт.

Получение этих аксессуаров не привело к появлению строк в текущей странице
«Автомобиль». Экран телеметрии либо отдельные строки/карточки для этой страницы
ещё нужно связать с данными. Логический showsInstruments-плагин не создаёт
реального дополнительного видеопотока приборной панели. Нельзя утверждать,
что значения уже видимы на приборке только на основании CAF-подписки.

поддерживают гипотезу слишком короткого интервала между импульсами. Для проверки

нужно вернуть частоту и при необходимости неактивную выбранную ступень вентиляции
водителя с 1 на 3, затем проверить кандидат opack-26 и отдельно исправить SeatFan UI.
