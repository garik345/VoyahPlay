# DiPlay Voyah Free — 0.1.1

Первый экспериментальный форк upstream `shihabal3amri/diplay`, commit `4bccb39`.
Цель: Voyah Free 2026 RU EREV, Android 11, платформа H97.
Основная сборка — модуль `mobile`, устанавливаемый непосредственно на ГУ.

## Реализовано

- Отдельное приложение `DiPlay Voyah`: release package `dev.voyah.diplay`,
  debug/preview package `dev.voyah.diplay.preview`. Оригинальный DiPlay остаётся установленным.
- Карточка на главном экране: BMS SOC, процент топлива, заданные температуры
  слева/справа и уровень вентилятора.
- Та же карточка в боковой панели CarPlay; поддержка боковой панели включена по умолчанию.
  Показ панели переключается в меню активного сеанса CarPlay.
- Выключатель обновления. Чтение раз в две секунды после успешного ответа,
  только при видимой карточке и активном окне. При уходе в фон чтение прекращается.
- Проверка точных SHA-256 двух OEM APK и типа H97 до чтения.
  Незнакомая прошивка блокируется, без переключателя обхода.
- При ошибке значения очищаются, автоматические повторные запросы прекращаются.
  При переходе между экранами занятый предыдущий запрос ожидается без создания новых потоков.
  Для повтора выключите и включите обновление.
- Скрытие показаний через шесть секунд без успешного ответа. У самого сигнала
  нет timestamp: свежий ответ сервиса всё равно может содержать старый кэш.
- Один общий рабочий поток и защита от накопления запросов при зависшем Binder.

Приложение читает локальный кэш мультимедиа. Адаптер не отправляет CAN-кадры,
не меняет климат, не подписывается на перехват кнопок и не передаёт эти значения
в разрешение видео в движении или расчёт запаса хода iPhone. CarPlay transport
сохранён из upstream. Скорость, TPMS, двери и окна пока не включены в панель.

## Поставляемая APK 0.1.1

`DiPlay-Voyah-0.1.1.apk` содержит runtime identity и сертификат из опубликованной
оригинальной DiPlay 0.2.13. Перенос явно разрешён пользователем. Файлы подключены
через предусмотренный upstream `DIPLAY_AUTH_ASSETS_DIR`; логика подключения CarPlay
не изменена. Их побайтовое совпадение с upstream проверяется после упаковки.

Пакет сохранён: `dev.voyah.diplay.preview`, versionCode 2. Устанавливайте поверх
0.1.0-preview для сохранения настроек. Подпись Android остаётся собственной тестовой
подписью форка; ключ подписи оригинального DiPlay не переносится.

Сам форк ещё не проверен на ГУ с iPhone. Совпадение runtime identity не гарантирует
совместимость со всеми версиями iOS; сохраняются ограничения upstream.
Исходный архив и CI-сборки не содержат runtime identity и ключей подписи Android.

## Сборка

Сохранены версии инструментов upstream: JDK 25, Gradle 9.5.0 (wrapper),
Android SDK 37.0, Build Tools 36.0.0, NDK 28.2.13676358.

```sh
./gradlew :common:testDebugUnitTest --tests 'com.shilapi.xcertplay.voyah.*' :mobile:assembleDebug
```

Результат: `mobile/build/outputs/apk/debug/mobile-debug.apk`.
Это **preview без runtime identity CarPlay**. Он предназначен для проверки интерфейса
и чтения данных Voyah; самостоятельное подключение iPhone им не подтверждается.
Для полноценного CarPlay требуются отдельно предоставленные runtime assets,
как предусмотрено upstream в [BUILD.md](BUILD.md):

```sh
DIPLAY_AUTH_ASSETS_DIR=/absolute/path/to/runtime-assets ./gradlew :mobile:assembleStandaloneDebug
```

Не добавляйте runtime identity или ключ подписи Android в Git. Автоматическая
сборка `.github/workflows/voyah.yml` создаёт только preview без identity.
Наличие workflow не означает, что он уже запускался или что репозиторий опубликован.

## Альтернативная сборка нативных библиотек на Linux

Если GNU Make в среде сборки аварийно завершается, можно собрать те же два C-файла
напрямую Clang из NDK. Этот путь использован для поставляемой APK; исходники C не
менялись. Обычная NDK-сборка остаётся вариантом по умолчанию.

```sh
export ANDROID_SDK_ROOT=/absolute/path/to/android-sdk
./scripts/build-voyah-native.sh
./gradlew -PvoyahPrebuiltJniDir="$PWD/build/voyah-jni" :mobile:assembleDebug
```

Скрипт собирает обе библиотеки для arm64-v8a, armeabi-v7a и x86_64 с API 28.
Gradle проверяет наличие всех шести файлов. Каталог `build` не входит в исходный архив.

## Проверка на автомобиле

1. Установите `DiPlay-Voyah-0.1.1.apk` поверх версии 0.1.0-preview или как отдельное приложение.
2. На стоянке откройте `DiPlay Voyah`. Карточка находится на главной странице;
   для её работы iPhone не нужен.
3. Сверьте SOC и климат. Измените климат штатным интерфейсом и вернитесь в DiPlay.
4. Проверьте выключатель обновления, уход в фон и возвращение.
5. После соединения iPhone откройте боковую панель в меню CarPlay. Используйте
   один приёмник CarPlay одновременно.

LO/HI климата и значения вне 16–32 °C пока показываются как недоступные (`—`).
Ноль топлива не пересчитывается в литры; ёмкость бака из OEM-объекта не используется.
