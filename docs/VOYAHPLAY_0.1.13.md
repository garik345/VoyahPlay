# VoyahPlay 0.1.13 — ISA/ISLC: только распознавание

Изменённые файлы поверх 0.1.12 с исправлением компиляции. Новый VoyahSignStateTest.java уже содержит это исправление. Распаковать в корень проекта, собрать с прежними assets и подписью. versionCode 14.

Меню тестов → «Знаки скорости: прочитать TSR / ISA». Под TSR появился отдельный переключатель ISA/ISLC. При открытии читаются оба состояния. Переключение доступно только при известном значении 1/2. Проверяйте на стоянке.

Включение:
1. Проверяется WRITE_CANBUS и состояние ISA «выключено».
2. Режим ISA_ISLC_MODE устанавливается в 4 (только распознавание), если отличается. Кэш должен подтвердить значение.
3. ISA_ISLC_OVER_SPEED_WARNING_SWITCH устанавливается в 1 (предупреждение выключено), если отличается. Кэш должен подтвердить значение.
4. Перед включением повторно проверяются режим 4, предупреждение 1, выключенное ISA.
5. ISA_ISLC_SWITCH устанавливается в 1. Затем выполняется контрольное чтение.

Выключение отправляет только ISA_ISLC_SWITCH=2. TSR не переключается. Значения режимов 2/3 и включение предупреждения исключены из списка разрешённых команд записи. Автовосстановление настроек не добавлено. Общие разрешения Apollo, ACC и ICA не записываются.

Порядок использует одиночный OEM setter TX58, а не прямые CAN-кадры. Обработчик setIVI_ADCU_Set проверен в пользовательском CAN APK; соответствие хеша обязательно. При отсутствии WRITE_CANBUS запись блокируется с текстом ошибки. Объявление разрешения в манифесте само по себе не выдаёт его.

При ошибке или неподтверждённом чтении дальнейшие шаги останавливаются. Уже принятые настройки могут сохраниться: транзакционного отката нет. Зависший Binder не даёт гарантии завершения; через 20 секунд окно показывает тайм-аут. OEM может обновлять кэш сразу после отправки, поэтому совпадение кэша не доказывает действие аппаратной системы или появление знаков. При ошибке сохраните отчёт.

Для проверки пришлите «Скопировать» после включения. Ожидаемые значения: ISA_ISLC_SWITCH=1, ISA_ISLC_MODE=4, ISA_ISLC_OVER_SPEED_WARNING_SWITCH=1. Отдельно сообщите, появились ли ограничения скорости на приборке. Эта функция включает штатное распознавание и не подставляет число из CarPlay.

Проверены статически порядок команд, ограничения записи и связь UI. Android-сборка и проверка на автомобиле не выполнялись.
