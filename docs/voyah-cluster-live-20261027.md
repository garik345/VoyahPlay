# Карта на приборке: аппаратная проверка 27 октября 2026

Текущая установленная сборка — opack-67, root-helper **1.2.7**.
[Исправление возврата карты и аппаратная проверка](voyah-cluster-return-20261027.md).
[Предыдущая аппаратная проверка opack-66](voyah-cluster-live66-20261027.md).
Ниже сохранены результаты аппаратной проверки opack-64 и подготовки диагностики opack-65.
На начало предыдущей проверки были установлены opack-64 и helper 1.2.7. Opack-65 добавляет диагностику
приближения и подготовлена без установки: ADB стал недоступен, пользователь выбрал
продолжить работу без автомобиля.
Проверка выполняется на исходном Voyah Free RU через ADB. Изменения размера
и геометрии opack-61 сохранены; при проверке найдены и исправлены ошибки автопоказа.

## Обновление

1. Установить [APK opack-66](../build/cluster-center66-20261027/voyahplay-opack-66-cluster-decoder-size-debug.apk)
   поверх текущего приложения с той же подписью.
2. При helper 1.2.6 или более раннем один раз выполнить установку помощника
   из текущих исходников. Если уже установлен 1.2.7, повторять её не требуется.
3. Проверить `HELPER_VERSION=1.2.7`, `HELPER_READY=1`,
   `CLUSTER_AUTO_CAPABILITY=VOYAH_CLUSTER_AUTO_1`, `BOOT_MOUNT_READ_ONLY=1`.
4. В «Дополнительно → Карта на приборке (экспериментально)» оставить включённым
   поток карты. Настройка размера надписей применяется после переподключения;
   кнопки приближения работают с уже открытой картой без переподключения.

[Полный порядок установки](INSTALL_NEW_CAR.md) включает поиск или установку ADB,
полный путь к `adb.exe` и `-Serial`, когда подключено несколько устройств.

В этой проверке opack-64 установлен, helper обновлён с 1.2.5 через 1.2.6 до 1.2.7.
Автозапуск helper сохранён включённым. Старый `BOOT_HELPER_VERSION` до перезагрузки
относится к предыдущей загрузке и не заменяет текущий `HELPER_VERSION`.
Перезагрузка мультимедиа при этой проверке не выполнялась.

## Что было исправлено

**Повторный запуск помощника.** В runtime оставалось ожидание живого сервера 1.2.3,
а PowerShell проверял 1.2.5 при объявленной версии 1.2.6. Runtime теперь сравнивает
ответ с собственной переменной VERSION, установщик проверяет текущую 1.2.7.
Точные проверки версии и capability сохранены; старые и неполные ответы отклоняются.

**Пересоздание карты примерно через 15 секунд.** На Android 11 `getTasks()` возвращает
baseIntent через `cloneFilter()`, без extras. Helper искал в них UUID и режим, поэтому
не узнавал собственное окно при продлении. Теперь сразу после root-запуска он
запоминает ID единственной собственной задачи в приватном разрешении. На каждом
продлении проверяются этот ID, компонент, пакет, пользователь и дисплей. Разрешение
по-прежнему ограничено 45 секундами с продлением раз в 15 секунд.

**Удаление карты отключало CarPlay.** Сервис соединения считал удаление любой задачи
приложения закрытием главного окна. Теперь он игнорирует удаление только собственного
`VoyahClusterProbeActivity`. Для главного CarPlay, другого компонента и отсутствующего
rootIntent прежняя остановка сохранена.

**Чёрный прямоугольник и неработающие кнопки приближения.** Автоматический вывод
передаёт публичный токен основного видеопотока. Контроллер сравнивал его с объектом
AirPlaySession; это разные объекты, поэтому запрос `showUI` не отправлялся.
Теперь запрос карты и zoom проверяют настоящий токен основного потока, в том числе
перед отправкой из очереди. Старый токен после re-SETUP или смены iPhone отклоняется.
Обычный запрос выбора контента без привязки к зеркалу сохраняет прежнее поведение.

## Результаты на автомобиле

- Автоматическое появление карты без ручного 60-секундного теста подтверждено пользователем.
- Полная высота прежней тестовой сетки подтверждена пользователем.
- При переходе 100% → 125% надписи и значки стали крупнее; пользователь подтвердил.
- В opack-64 запрос карты принят (`mapRequestAccepted=true`), принимаются и выводятся
  живые кадры. Зафиксировано около 25–30 кадров/с, `nonBlackPixels=256/256`, 147 цветов
  в контрольной выборке. Выборки не сохраняют изображение маршрута.
- Helper 1.2.7 установлен и сообщает capability автоматической карты; системный
  раздел после установки остаётся read-only. Основной экран CarPlay и кнопки Ultra
  видны при работающей карте.

Длительную непрерывность одного и того же окна и остановку после завершения маршрута
до потери ADB не успели зафиксировать. `auto-long.xml` и `root-lease-long.json` в
каталоге opack-64 пусты из-за обрыва связи и не являются результатами проверки.

## Приближение дорог: проверка не завершена

В opack-64 пользователь подтвердил живую карту, но не увидел изменения приближения
после нажатий кнопок. Проверку с Apple «Картами» выполнить сейчас не смог; ADB
отключился до получения журнала этих нажатий. Нельзя заключить, что навигатор
игнорирует команду, пока не проверена её отправка на этом подключении.

В opack-65 «Скопировать отчёт теста» в карточке карты добавляет:

```text
PROBE_ZOOM_DIRECTION=in / out / none
PROBE_ZOOM_SENT=true / false / pending / none
PROBE_ZOOM_REASON=sent / no-active-session / stream-not-active / map-not-visible / ...
PROBE_ZOOM_AGE_MS=...
```

`true` означает запись команды в канал iPhone, без подтверждения изменения карты
навигатором. В журнале подключения также есть строка `Dashboard zoom` с направлением,
результатом и причиной. Старая обратная связь не затирает результат более нового нажатия.

При следующей проверке установить opack-65 (helper 1.2.7 уже подходит), запустить
маршрут Apple «Карт», нажать приближение 3–5 раз с паузами, затем отдаление и
скопировать отчёт. Повторить в используемом навигаторе. При `false` причина указана
в отчёте; при `true` и отсутствии эффекта сравнить поведение навигаторов. Копирование
отчёта не запускает ручной тест и не приостанавливает автоматическую карту.

## Проверки кода

Профиль: **464 JVM-теста**, common 176 и shared 288, без ошибок. Добавлены проверки
сохранения задачи без Intent extras, отклонения чужих задач и дисплеев, закрытия
вспомогательной задачи без остановки сервиса, принятия публичного токена и отказа
старому токену после re-SETUP, смены телефона и задержки в очереди отправки.

Пять проверок запуска helper и проверки top-bounds проходят. Диагностика отправки
и отказа по устаревшему токену также проверена тестами. Снимки настроек
с крупным шрифтом RU compact/full и Arabic RTL сохранены в отчёте
[масштаба](voyah-cluster-scale-20261027.md); свежие снимки opack-65 также сохранены
в `build/cluster-zoom65-20261027/screenshots/` и просмотрены. Общий CI opack-64 выполнен по AGENTS.md:
те же 78 старых падений shared, 20 ошибок компиляции старых common-тестов и конфликт
minSdk mobile/common. Имена отказов совпали с opack-61. Общий CI opack-65 также
выполнен: 1710 shared-тестов, 79 отказов. Сохранились все 78 прежних падений;
