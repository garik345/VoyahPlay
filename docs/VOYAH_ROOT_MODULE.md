# Прежний системный модуль удалён

Начиная с root-помощника 1.1.0 отдельный модуль с собственным инъектором
исключён из APK и меню. Старые команды его включения не принимаются.
Рабочая полная ширина использует добавку Tweaks 1.1.

Актуальная инструкция: [VOYAH_ROOT_HELPER.md](VOYAH_ROOT_HELPER.md).
Миграция удаляет старый исполняемый payload после проверки восстановления,
сохраняя журналы и записи попыток на ГУ.
