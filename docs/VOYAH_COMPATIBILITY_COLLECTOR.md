# Проверка другой прошивки ПИ

[Пересылаемый ZIP с ADB и START.cmd](../build/pi-compatibility-20261028/release/Voyah-PI-compatibility-1.0-with-ADB.zip).
Комплект не требует установленного в Windows ADB, Android Studio, исходников
и установленного на машине VoyahPlay. Он получает материалы для анализа прошивки;
совместимость не включается автоматически и проверки хешей приложения не снимаются.

## Что сказать владельцу

1. Распаковать весь ZIP в обычную папку, подключить мультимедиа по ADB.
2. Открыть VoyahPlay, если он установлен, и запустить **START.cmd** двойным щелчком.
   При нескольких устройствах выбрать автомобиль по номеру.
3. Первые 20 секунд предназначены для записи состояния окон. На стоящем автомобиле
   изменить громкость и открыть штатный климат, если проверяется вспышка дока.
   Для обычного сбора совместимости можно ничего не нажимать.
4. Дождаться завершения извлечения файлов. Передать **новый** архив
   `Voyah-compatibility-....zip` с рабочего стола.

Нужен уже существующий root через `su 0` или adbd, работающий от root. Если его нет,
сохраняются доступные публичные файлы и отчёт с ограничениями. Неизвестная версия
Android не блокирует сбор; наличие приложения/helper тоже не является условием.
Сборщик не устанавливает root и не выполняет `adb root`.

## Состав

- Сведения о прошивке, Android, геометрии экрана и версиях OEM-служб.
- CAN/CarSignal APK, SDK QGVehicle/QGAPI и системные JAR; при необходимости поиск
  SDK в `system_ext`, `vendor`, `product`. Split APK сохраняются отдельно.
- Launcher, SystemUI, QGBus, оконная политика, приборка, настройки автомобиля,
  радио и обнаруженные OEM-службы климата/громкости.
- services.jar, файлы Tweaks, исходный загрузочный hook, сохранённый оригинал hook
  и метаданные установленного helper. Изученный injector повторно не копируется,
  его сумма сохраняется; неизвестный выпуск извлекается.
- Снимки окон, журнал запросов скрытия дока, состояние разрешений полного экрана,
  ограниченный журнал приложения/helper.
- `summary.json`: точные пути, длины и SHA-256 файлов, успешность получения,
  причины пропуска; `report.txt`: выполненные чтения и результаты.

APK VoyahPlay не копируется: сохраняются его версия, разрешение WRITE_CANBUS и SHA-256.
Идентификаторы сопряжений и данные iPhone не читаются. Полный список пользовательских
приложений не записывается. Текстовые MAC/IP и явно обозначенные персональные поля
редактируются; APK/JAR/бинарные скрипты не меняются, чтобы сохранить проверяемые суммы.

Все команды на машине читают данные. Установок, записи настроек, команд CAN,
инъекций и перезапусков нет. Копирование выполняется через бинарный поток ADB,
с ограничениями времени/размера и обязательной сверкой длины/SHA-256. Повреждённый
файл удаляется локально и отмечается в отчёте. Недоступный компонент не отменяет
получение остальных файлов. Общий предел — 1.5 GiB; отдельные OEM-настройки до 512 MiB.

## Вспышка левого дока

Пользователь подтвердил установку ПИ-пакета helper 1.2.8 после исправления имени
функции hash. Теперь при штатных всплывающих окнах громкости/климата иногда виден док.
В `VoyahDockVisibility` есть запросы скрытия с периодом 250 мс, обработка фокуса
и сохранение владельца под видимыми полупрозрачными окнами. Поэтому гипотеза —
Launcher повторно показывает док при смене активного окна до следующего запроса.
Это ещё не доказано журналом именно этой машины.

Для устранения вспышки нужны Launcher этой ПИ и события во время всплывающего окна.
Сборщик включает оба. До их получения обработчик Launcher и код скрытия дока
не менялись. Требуется сохранить штатные шторки, камеры и возврат панелей после
выхода из VoyahPlay; одного учащения запросов недостаточно для доказанного решения.

## Локальная сборка и проверка

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\diagnostics\build-voyah-compatibility-bundle.ps1 `
  -AdbDirectory 'C:\Tools\platform-tools' -OutputDirectory '.\build\compatibility-bundle'
```

Скрипт поставки копирует только adb.exe, две DLL, NOTICE, метаданные Platform-Tools,
два PowerShell-скрипта, START.cmd, README и manifest. Ключи ADB, APK автомобиля,
предыдущие отчёты и исходники VoyahPlay в исходный пересылаемый ZIP не включаются.

На имитаторе ADB проверены Windows PowerShell 5.1, кириллица/пробелы в пути,
бинарные байты NUL/невалидного UTF-8, split APK, отсутствие VoyahPlay/root,
adbd-root, Android 9, SDK на других разделах, выбор устройства, неизвестный injector,
недоступные/повреждённые/растущие/слишком большие файлы и отбрасывание опасных путей.
Также проверен список отправленных команд: только чтение. Это локальные проверки;
настоящий отчёт с другой машины ещё предстоит получить.

Обязательный общий CI выполнен; сохраняется прежний набор 78 падений shared,
20 ошибок компиляции старых common-тестов и конфликта minSdk mobile/common.
Сравнение с предыдущим прогоном и материалы сборки — `build/pi-compatibility-20261028/`.
