# DiPlay Voyah 0.1.4: файлы для самостоятельной сборки

Архив содержит накопленные изменения относительно исходников 0.1.1:
кнопку ⚙ и режим без жеста, четыре двери и четыре окна, ручной тест текста
на приборной панели. Файлы заменяются от корня проекта. Локальные правки
версий 0.1.2/0.1.3 предварительно сохраните: их исходники не предоставлены.

Версия APK: 0.2.13-voyah.0.1.4-preview, versionCode 5.

## Сборка

В комплект включены local-auth/offline-mfi/identity.pk8 и certificate.p7b,
побайтно извлечённые из предоставленного рабочего APK 0.1.1.
Сборка из корня проекта:

```bash
bash scripts/build-voyah-standalone.sh
```

Скрипт подключает local-auth через DIPLAY_AUTH_ASSETS_DIR и использует
assembleStandaloneDebug. Дополнительные аргументы Gradle передаются дальше.
Используйте прежний ключ подписи APK для обновления установленного приложения.
QGAPI.jar не включается в приложение: используются системные классы автомобиля.

## Проверка

1. Проверьте подключение CarPlay.
2. В настройках «Управление CarPlay» выберите «Только кнопка — без жеста».
   В окне CarPlay настройки открываются кнопкой ⚙.
3. В боковой панели проверьте четыре двери (0 закрыто, 1 открыто) и окна
   (0 промежуточное положение, 1 полностью открыто, 2 закрыто).
   Иные значения показываются как «нет данных». Капот, багажник, люк и замки
   не интерпретируются по неподтверждённой расшифровке.
4. На стоянке завершите штатную навигацию, затем в настройках DiPlay нажмите
   «Voyah: тест текста на приборной панели». Тест не требует подключения iPhone.
   Он отправляет ROAM с названием текущей дороги «ТЕСТ DIPLAY», без стрелки.
   Через 10 секунд или по кнопке остановки отправляется MAN_STOP с пустым
   названием дороги. Проверьте появление текста и его последующее исчезновение.
   Успешный Binder-вызов сам по себе не доказывает отображение/очистку.
   При зависшем Binder автоматическая очистка не гарантирована; сообщение
   об этом появится через 20 секунд. Повторные тесты блокируются до окончания
   зависшего запроса. Логи доступны под тегом VoyahNavigationTest в logcat.

Тест ограничен SHA256 проверенных InstrumentCluster APK и QGAPI.jar.
Он может заменить штатную навигационную подсказку, не восстанавливает маршрут
другого приложения и не проверяет скорость по CAN.
Автоматическая передача реальных манёвров CarPlay в этой версии не включена.

## Проверки при подготовке

Сверены схемы CAN 2/44 с диагностикой, проверены размеры полей и упаковка,
побайтово сверены два файла авторизации. Добавлены проверки неизвестных
состояний и длины ответов Parcel. JUnit и Android-сборка не запускались:
в текущей среде нет рабочего Android SDK/JDK. На автомобиле не проверено.
