# Амбиентная подсветка и ароматизатор в CarPlay

28 октября 2026. Подготовленная сборка `opack-70-cabin-controls`, automotive/debug.
Автомобиль не подключён к ADB; сборка подготовлена без аппаратной проверки.
Установка поверх текущего APK сохраняет настройки. После установки нужно
переподключить iPhone для получения нового описания CAF. Root-helper остаётся 1.2.7.

## Элементы «Автомобиль»

| Регулятор | Значения | Источник состояния |
| --- | --- | --- |
| Амбиентная подсветка | Выкл / Включено | VEHICLE_AMBIENT_LIGHT_SWITCH, OEM 1/2 |
| Яркость подсветки | 1–10 | VEHICLE_AMBIENT_LIGHT_BRIGHTNESS_LEVEL |
| Цвет подсветки | 1–64 | VEHICLE_AMBIENT_LIGHT_COLOR |
| Интенсивность ароматизатора | 0 = выкл, 1–3 = включён на выбранном уровне | FCM_SW_REQ и IVI_FRAG_CONCERNTION |
| Картридж ароматизатора | 1–3 | IVI_FRAG_TASTE |
| Время ароматизации | Постоянно / 30 / 60 минут | FCM_DURATION_CONTROL, OEM 0/1/2 |

Подсветка расположена после наружного света, ароматизатор — после управления
массажем. Меню автомобиля и настройки VoyahPlay сохраняются первыми. Стандартный
экран громкости не меняется. Используются те же CAFIntegerSetting и подтверждение
записей, что у существующих регуляторов автомобиля.

Для девяти цветов есть локализованные названия, проверенные по штатному коду:
синий 1, голубой 8, фиолетовый 10, зелёный 19, розовый 30, жёлтый 49, коричневый 54,
оранжевый 61, красный 64. Остальные показывают свой номер из 64. Это регулятор
штатной палитры, не произвольный RGB-пикер. Картриджи обозначены номерами: индивидуальные
названия, заданные в штатном приложении, не угадываются.

## Команды и чтение

Добавлены абсолютные команды, независимые от циклических команд старой панели
VoyahPlay. Установка интенсивности 1–3 сначала задаёт её, затем включает ароматизатор.
Ноль выключает его, сохраняя выбранный картридж, таймер и запомненную интенсивность.
Выбор картриджа или времени не включает ароматизатор. Переключатель подсветки
и её яркость независимы: выбранная яркость сохраняется при выключении.

Все команды требуют существующего WRITE_CANBUS и проверки CAN APK RU/ПИ.
Новые поля подсветки дополнительно сверяются по имени, ordinal и ID с установленным
OEM SDK перед записью. Значения вне диапазона, неизвестное состояние и неуспешные
записи не подтверждаются. Отдельный CABIN_CONFIRMED исключает ложный успех, если
защитная проверка запретила запрос, а старый кэш случайно уже содержал нужное число.

Текущее значение приходит из штатного TX57-кэша, включая изменения штатными органами
управления. Подтверждение кэшем не заменяет проверку физического действия на машине.
Давность этих значений отдельна от громкости и событий наружного света. Отсутствие
необязательных полей подсветки не отбрасывает уже прочитанный климат и сиденья.

## Ограничения первой проверки

Ручные цвет/яркость доступны при выключенном музыкальном режиме подсветки
(VEHICLE_AMBIENT_LIGHT_MUSICAL_RHYTHM_SWITCH=1). Музыкальные эффекты и привязка
к темам не отключаются автоматически. При активном музыкальном режиме сначала
отключите его в штатном меню автомобиля. Изменение яркости/цвета не включает
выключенную подсветку: для этого есть её отдельный регулятор.

В этой сборке управление идёт через штатный CAN. Работа всех зон подсветки,
синхронизация экранной части ScreenLamp и влияние штатных автоматических эффектов
требуют проверки на автомобиле. Эти проверки не заявлены выполненными.
Ранее обнаруженное несовпадение services.jar на ПИ остаётся отдельной задачей
полного экрана; в opack-70 проверка файлов Tweaks не изменена.

## Установка на RU 28 октября

Opack-70 установлена поверх opack-67 на подключённую RU H97x-650.
SHA-256 установленного APK совпал с подготовленным файлом; UID 10114 и WRITE_CANBUS
сохранились. CarPlay переподключился автоматически, в /info и CAF CONFIG подтверждена
opack-70. На экране открыт автомобильный раздел: видны новые регуляторы подсветки.
В штатном кэше получены включение подсветки, яркость 5, цвет 5; ароматизатор 3,
картридж 3, время 0. Самими регуляторами при установке не управляли: проверку
физических действий выполняет пользователь. Это ещё не подтверждение работы всех зон.
Материалы: `build/device-cabin70-20261028/`, включая прежний APK для отката.
