# Профиль Ultra из приложения без ADB: opack-47

26 октября 2026. WIRE_REV `opack-47-ultra-profile`.

В debug-варианте единый переключатель «Климат и комфорт через CarPlay Ultra»
теперь включает всю проверенную конфигурацию: CAF/UI Sync, MFi4, объявление темы
в iAP2 Identification/CarPlayStartSession, имена дисплеев и displayPanels.
Для новой установки не нужны редактирование XML, ADB или root-helper.

Единственный источник состояния — `voyah_ultra_pilot.enabled`, по умолчанию false.
`carPlayTheme()` больше не зависит от скрытого themeProbe; передача профиля
панелей в createExtension следует этому же состоянию. Существующие точки
подключения в CarPlayHostActivity заново читают его при создании конфигурации
приёмника. Кнопка сохраняет настройку через прежний markReconnectNeeded:
работающий CarPlay сам не отключается, изменение применяется при следующем
подключении или выбранном пользователем переподключении.

Профиль и его содержимое не заменены: используются прежние `44C9FA31EC:985:19.0`,
Center_Display и Cluster_Display. Пиксельный холст остаётся 1920×720, физический
размер берётся из выбора масштаба. Это диагностический пример LIVI, не новая тема
Voyah; ресурсный пакет не добавлялся в APK. Логическая приборная панель не означает
вывод карты на физическую приборку.

Миграция настроек версии 5 удаляет устаревшие themeProbe, panelProbe и mutualAuth,
сохраняя enabled, радио, масштаб и данные подключения. Поэтому существующий
включённый Ultra получает профиль автоматически; выключенный остаётся выключенным.
Восстановленные старые отладочные флаги также игнорируются. При выключении общего
переключателя исчезают профиль, MFi4 и расширение CAF/UI Sync вместе.
Запись пакетов остаётся выключенной. Release-вариант по-прежнему не содержит Ultra.

Описание переключателя обновлено во всех восьми локалях. README и инструкция новой
установки обновлены: блок ADB-редактирования Ultra-настроек удалён. Root-helper для
полного экрана остаётся 1.2.1 и не требует обновления из-за данного изменения.

284 профильных теста прошли без ошибок. Новый тест стартует с пустыми preferences,
включает Ultra только публичным методом и проверяет фактический /info:
Center_Display, размер 1920×720, связь панели с видеопотоком и CAF-конфигурацию.
Также проверены прежние false/true флаги, миграция с версий 3/4, выключение,
сохранение выбора радио и масштаба, все размеры интерфейса. UI-тест переключает
реальную строку настроек и проверяет MFi4 и профиль. Снимки fontScale 1.5:
компактный русский, полный русский с высокой плотностью, компактный Arabic RTL.

Профильные common-тесты используют существующий init-скрипт, исключающий старые
несовместимые src/test; общая команда CI из AGENTS.md выполняется отдельно.
Артефакты: `build/ultra-profile-20261026/`, `profile-results/`, `screenshots/`.
На автомобиль APK не установлен: по последнему сообщению он недоступен.
Для подтверждения чистой установки на другом ГУ ещё нужна проверка с iPhone.

Обязательная общая команда CI выполнена с automotive assemble. Shared: 1700 тестов,
78 падений; список имён совпадает с сохранённым baseline. Сохраняются прежние
ошибки компиляции старых common-тестов и конфликт minSdk mobile=25/common=28.
Общий CI не зелёный, automotive APK и профильные проверки успешны.
Ссылки/якоря документации, PowerShell-блоки оставшейся инструкции и описания
переключателя во всех восьми локалях проверены; git diff --check пройден.
