# VoyahPlay 0.1.6

Патч поверх DiPlay Voyah 0.1.5. Предыдущие исправления окон и рабочая навигация
сохраняются. Сборка: `bash scripts/build-voyah-standalone.sh`.
Используйте прежнюю local-auth и прежнюю подпись APK. versionCode 7.
Application ID оставлен прежним для установки обновлением с сохранением настроек.

## Проверка PhoneInfo

На стоянке отключите CarPlay, закройте его окно и отключите телефон от Bluetooth
автомобиля. Этот ручной тест не отслеживает реальные звонки.

Настройки → «Voyah: тест приборки — стрелки и нижняя строка».
Сначала выберите «Нижняя строка: входящий звонок», затем отдельно «Нижняя строка:
разговор». Каждый тест отправляет PhoneInfo с именем «ТЕСТ VOYAHPLAY», пустым
номером, duration=0, vehicleCall=0 и состоянием COMING_CALL либо CONNECTED.
Это только сведения для приборки: номер не набирается, звонок не совершается.
Через 10 секунд либо по остановке отправляется NOTHING с пустыми строками.

Пришлите фото каждого варианта и проверьте, вернулись ли часы/температура после
очистки. Запишите, появились ли значок телефона и таймер и где показан текст.
Тест не включает музыку, бегущую строку или автоматическую подмену звонков.
SHA256-проверки InstrumentClusterService и QGAPI.jar сохранены.
При зависании Binder очистка не гарантирована; сообщение появится через 20 секунд.

## Название и интерфейс

Название приложения, основные видимые подписи, уведомление, виджет и публичное
имя при подключении CarPlay заменены на VoyahPlay. BYD в локализованных подписях
заменён на Voyah. Предыдущие стандартные значения производителя/модели и метки
автомобиля при загрузке заменяются на VoyahPlay/Voyah; пользовательские значения
не перезаписываются. Для обновления имени у iPhone может потребоваться переподключение.

Технические имена классов, resource ID, SDK, имена сохранённых ключей и протокольные
идентификаторы не переименованы. Детекторы настоящих BYD не превращены в детекторы
Voyah: изменение названия пункта не добавляет поддержку несовместимой функции.
Упоминания исходного DiPlay в авторских/лицензионных сведениях сохранены.

Проверены XML ресурсов, состав патча и ветки выбора PhoneInfo/NaviInfo.
Компиляция, JUnit и тест PhoneInfo на автомобиле не выполнялись.
