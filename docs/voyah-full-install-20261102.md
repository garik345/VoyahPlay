# Полный комплект и доступность функций — 2 ноября 2026

Ревизия APK: `opack-96-install-features`; helper `1.2.16`, мост `1.1`.
Пользовательская инструкция: [установка полного комплекта](INSTALL_FULL_BUNDLE.md).

## Проверка функций

`VoyahFeatureAccess` получает ответ через Unix-сокет helper с проверкой root UID
сервера, версии, возможностей и привязки к UID APK. Доказательства хранятся только
в памяти процесса. Проверки выполняются в отдельной очереди и объединяются;
интервал обновления 15 секунд, срок действия результата 45 секунд. Ошибка не
обходит сокет прямым вызовом su. Данные сохранённых настроек доступ не предоставляют.

- Ultra требует совместимый, отвечающий helper.
- Док и статус-бар требуют подтверждённый TWEAKS_STATUS, проверенные файлы
  прошивки/моста и FULLSCREEN_PREREQUISITES_READY=1.
- Новый helper проверяет свежие статусы top/status/dock, их PID, версию и отсутствие
  ошибки. Отключённая пользователем функция не требует активного lease: достаточно
  готового установленного обработчика. Это позволяет сначала проверить, затем включить.
- Автокарта дополнительно требует capability текущей версии helper, единственный
  подходящий дисплей и проверенную пару APK приборки / QGAPI этой машины.

Перед созданием нового контроллера CarPlay асинхронная проверка завершается;
устаревший callback не запускает контроллер другого поколения. Отказ оставляет
обычный CarPlay доступным. Уже идущая сессия проверкой не переподключается.
Загрузка настроек Ultra/панелей/карты проверяет доступность повторно; API сохранения
не принимает включение заблокированной функции. Выбор, ранее сделанный при
готовых компонентах, сохраняется при временной недоступности.

## Настройки

VOYAH_HELPER перемещён из Advanced в Diagnostics и имеет одну категорию.
В Advanced сохранены функции Ultra, радио, RDS-подписей OEM-радио, автоматической
карты и её размера, разделённого окна. Удалены ручные MEDIA/NAVI/AR тесты,
копирование тестового отчёта и команды географического приближения.
Их внутренние протоколы helper сохранены для совместимости установленных версий.
Изменения Ultra/радио/карты показывают необходимость следующего подключения.

Описания сокращены; новые строки переведены на все восемь локалей проекта.
Макеты с fontScale=1.5 сохранены в `build/install96-20261102/screenshots`:
compact RU 320dp, full RU 1000dp с плотностью 320dpi, compact Arabic RTL.
Проверены переносы, высота кнопки выбора размера и отсутствие тестовых кнопок.

## Установщик

Один INSTALL.cmd включает выбор ADB-устройства, проверку Android/root и точной
пары services.jar/SystemUI, подготовку штатного Tweaks при отсутствии приложения,
обновление APK, моста и helper. Поддержаны RU H97, PI OTA7.0 build86, PI OTA7.2
build35. Неизвестная пара останавливает установку до записи; COLLECT.cmd сохраняет
данные для адаптации. При нескольких устройствах выбирается номер либо serial;
при одном serial не нужен. В комплекте собственный Windows ADB.

Активацию и подготовку Tweaks владелец выполняет штатно. В поставке есть проверенные
VoyahTweaks 2.9.0, injector и QGWindowPolicy; неизвестные установленные файлы ими
не заменяются. Файлы OEM другой машины и её данные активации не переносятся.
Мост сохраняет оригинал этой машины; RESTORE_BRIDGE.cmd использует только его.
Перезагрузка выполняется владельцем. Обновление не удаляет APK при ошибке подписи.
