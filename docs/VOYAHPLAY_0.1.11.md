# VoyahPlay 0.1.11 — чтение TSR / ISA

Изменённые файлы поверх 0.1.10. Распаковать в корень проекта и собрать прежним способом, сохранив assets аутентификации и подпись. versionCode 12.

Меню тестов приборки → «Знаки скорости: прочитать TSR / ISA» → «Прочитать».
Окно показывает TSR_SWITCH, TSR_OPERATING_STATUS, TSR_SPEED_LIMIT, TSR_SPEED_LIMIT_UNIT, ISA_ISLC_SWITCH, ISA_ISLC_MODE, ISA_ISLC_OVER_SPEED_WARNING_SWITCH, ISA_ISLC_STATUS.

Это только чтение кэша getVehicleState (TX57). Команды включения, изменение ISA/круиза и вывод тестового знака не выполняются. Работает и при активной сессии CarPlay. Проверяется точный SHA-256 CAN APK; формат Parcelable (presence, ordinal, stable ID) и все восемь пар номеров сверены с предоставленным владельцем APK.

Сделайте снимки при отсутствии и наличии штатного знака, а если получится — при разных ограничениях. Запишите, какой знак был виден в момент каждого чтения. Кнопка «Скопировать» копирует историю с временем. История хранится в памяти процесса, до 16000 символов; повторное открытие окна её сохраняет, перезапуск приложения очищает. Операции с экраном выполняйте на стоянке или поручите пассажиру.

-1 — нет значения в кэше, а не доказательство отсутствия аппаратного распознавания. Единицы и состояния без подтверждённой расшифровки показаны сырыми. Если знак виден, а TSR_SPEED_LIMIT=-1, сообщите именно это. DENIED/SecurityException означает недостаток прав обычного приложения; права автоматически не выдаются.

Проверка: формат TX57 и номера полей сопоставлены с дизассемблированным CAN APK, проверено отсутствие других transact в новом модуле. Android-сборка и проверка на автомобиле не выполнялись.
