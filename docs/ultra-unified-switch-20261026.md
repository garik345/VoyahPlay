# Единое включение климата Ultra и MFi4: opack-45

26 октября 2026. WIRE_REV `opack-45-ultra-switch`.

В «Дополнительно → CarPlay Ultra: климат и комфорт» оставлен один переключатель
«Климат и комфорт через CarPlay Ultra». Он включает и отключает одновременно
расширение CAF/UI Sync и предложение авторизации MFi4. Отдельный переключатель
MFi4 и его строки удалены. Новый текст описания переведён во всех восьми локалях;
он явно указывает применение при следующем подключении CarPlay.

Единственный источник состояния — существующий `voyah_ultra_pilot.enabled`.
`isMutualAuthEnabled()` читает его же; отдельного способа сохранить MFi4 больше нет.
`CarPlayHostActivity` использует этот getter при создании AirPlayConfig, а
`createExtension()` — то же состояние для CAF/UI Sync. Сама реализация MFi4,
выбор сертификата и подпись не менялись. Release-вариант по-прежнему не включает Ultra.

Миграция профиля версии 4 удаляет устаревший `mutualAuth`, сохраняя выбор климата:

| Старый enabled | Старый mutualAuth | Новый Ultra и MFi4 |
| --- | --- | --- |
| false | false | выключены |
| false | true | выключены |
| true | false | включены |
| true | true | включены |

Старое значение `mutualAuth`, восстановленное после миграции, также игнорируется.
На новой установке оба режима по умолчанию выключены. Настройки радио, масштаба,
темы и сохранённого подключения не сбрасываются. Переключатель вызывает существующий
`markReconnectNeeded()`: работающий CarPlay самостоятельно не прерывается.

Профильные проверки: 196 тестов, 0 ошибок. Проверены переключение обоих состояний,
все четыре сочетания старых настроек, повторная миграция, восстановление старого
значения, сохранение выбора радио/темы/масштаба/данных подключения. UI-тест нажимает
единый переключатель и проверяет оба getter; в карточке ровно два переключателя —
Ultra и независимое радио. Снимки при fontScale 1.5: 320 dp, 1000 dp/320 dpi и
компактный Arabic RTL. Артефакты: `build/ultra-switch-20261026/`.
