# Названия радиостанций в CarPlay — 25.10.2026

Ревизия `opack-33-radio-names` добавляет название станции в основную подпись
списка: `FM 101.7 MHz · Название станции`. Это пример формата, а не справочник
соответствия частот и станций.

До изменения в CAF MediaItem поле `mediaItemName` содержало частоту, а
`mediaItemShortName` — название. В списке CarPlay пользователь видел частоту.
Экран «Исполняется» получал название отдельно, через NowPlaying.Artist.
Теперь `mediaItemName` объединяет частоту и доступное имя станции.

Данные берутся из штатного радио:

- Локальный APK: `RdsInfoUtils.buildQinMediaInfo` переносит RadioStation.PSName
  в QinMediaInfo.artist. Конструктор QinQueueItem переносит artist в subtitle
  стандартного MediaDescriptionCompat.
- Для остальных станций используется название из OEM-списка.
- Для текущей станции свежее название из метаданных используется сразу,
  даже если штатный список ещё не обновлён. Сопоставление идёт по диапазону и
  частоте, а не по позиции в списке.
- Если имени нет, отображается частота. Пустое имя и повтор самой частоты
  не создают лишнюю подпись.

Идентификаторы, частоты, OEM-индексы и обработчики переключения станций
не меняются. В «Исполняется» частота и название по-прежнему передаются своими
полями. Постоянный справочник названий по частотам не создаётся: соответствие
может различаться в разных городах.

Целевые проверки: 118 shared Ultra/UI Sync и 25 common Voyah, всего **143**,
без ошибок. Новые сценарии проверяют передачу имени в CAF, обновление RDS
без смены станции, FM/AM с одинаковым числовым ID, сохранение OEM-индексов,
отсутствие дублирования частоты и текущую станцию вне списка.
