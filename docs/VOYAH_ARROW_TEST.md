# Ручной тест стрелок: дополнение к DiPlay Voyah 0.1.4

Замените файлы из архива от корня проекта, затем соберите привычным способом:
`bash scripts/build-voyah-standalone.sh`.
Версия и файлы авторизации этим патчем не меняются. Исправление окон применяется
отдельным ранее выданным патчем; данный архив его не отменяет.

На стоянке, завершив маршрут в штатной навигации:
1. Настройки DiPlay → «Voyah: тест приборки — текст и стрелки».
2. «Стрелка по коду (0–31)» → выберите код → «Выбрать» → «Начать тест».
3. В приборку отправляется GUIDING, tbtIconId с выбранным кодом, nextDistance=300,
   turnRoadName «ТЕСТ КОД N». Значения кодов не подписаны направлениями заранее.
4. Через 10 секунд либо после остановки отправляется MAN_STOP с пустым названием.
   Дождитесь завершения и проверьте исчезновение подсказки перед следующим кодом.
5. Начните с кодов 1–12; пришлите фотографии или список «код → изображение».
   Если стрелки нет, укажите, появились ли название теста и расстояние.

Диапазон 0–31 выбран для первого ручного обследования, это не подтверждённая
таблица стрелок и не утверждение, что других кодов нет. Автоперебора нет.
Тест не требует iPhone. Выход из диалога запрашивает остановку.
Успешный Binder-вызов не гарантирует фактическое отображение или очистку.
Сохраняются SHA256-проверки сервисного APK/QGAPI.jar и ограничение повторного
запуска, пока предыдущий запрос не завершился. При зависшем Binder через
20 секунд появится предупреждение; очистка тогда не гарантируется.

Компиляция и автомобильная проверка нового режима не выполнялись.
