# VoyahPlay 0.1.14

Изменённые файлы поверх 0.1.13. Скопировать в корень проекта с заменой. Сборка прежним способом, с прежними assets аутентификации и подписью. versionCode 15.

Из интерфейса удалены:
- раскрываемые дополнительные данные BYD/DiLink с выбором старых способов чтения;
- экспериментальный DiLink 4 ADB-вывод и его кнопки авторизации/запуска;
- BYD-раздел навигации/HUD и его настройки песен, звонков и экспериментальных DiLink 3 кнопок.

Сохранённое включение DiLink ADB-маршрутизации игнорируется. Общая карта CarPlay, геопозиция, раздел Voyah, штатная передача стрелок, бегущая строка и переключатели TSR/ISA остаются. Внутренние классы с историческими именами BYD/DiLink не переименовывались: часть общих парсеров используется работающими функциями Voyah.

Стандартный значок возврата в автомобиль заменён на Voyah: белый знак и надпись на тёмном фоне, PNG 256×256. Один ресурс используется для предпросмотра и передачи iPhone. Для обновления значка переподключите CarPlay. Если ранее выбрано пользовательское изображение, откройте настройку значка кнопки автомобиля → «По умолчанию», затем переподключитесь.

Источник векторного знака: https://brandlogos.sgp1.digitaloceanspaces.com/svg/cbi/voyah.svg (Custom Brand Icons, указание источника: https://superdevpro.com/brands/voyah). Voyah — товарный знак правообладателя. Приложен SVG оформления для воспроизводимого рендера.

Проверены ссылки UI на удалённые пункты, квадратный PNG и использование общего ресурса значка. APK не собирался, проверка на автомобиле не выполнена.
