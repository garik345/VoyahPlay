# VoyahPlay 0.1.10

Изменённые файлы поверх 0.1.9. Распаковать в корень проекта с заменой файлов; сборка прежним способом с прежними ключами и assets.

Меню приборной панели → «Настройки бегущей строки»:
- Скорость: интервал 200–1500 мс на символ, шаг 50 мс. Вправо — быстрее.
- Количество: 6–30 символов одновременно.
- «Сохранить» применяет оба значения; «Отмена» ничего не меняет; «По умолчанию» возвращает 10 символов и 650 мс.

Оба параметра сохраняются между запусками, применяются к тесту и автоматическим названиям треков. Текущий показ при сохранении начинает прокрутку заново. Длительность по-прежнему ограничена 30 секундами. Реальная ширина зависит от шрифта приборки: при обрезании уменьшите число символов. Для emoji окно автоматически сокращается до лимита 60 байт UTF-16, без разрыва пары суррогатов.
