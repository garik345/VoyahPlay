### VoyahPlay 0.1.23 — эксперимент чтения климата через CarPlay Ultra

- Только debug: выключенный по умолчанию пункт «CarPlay Ultra: климат водителя (экспериментально)» в разделе «Дополнительно». Изменение применяется после сохранения и повторного подключения CarPlay.
- Реализован первый этап Vehicle State Protocol / CAF: описание одной климатической зоны, чтение заданной температуры водителя, подписка и уведомления об изменениях. Источник — проверенный VoyahClient, поле airLeftTemperature. Температура салона не подменяется заданной температурой.
- Свежие завершённые чтения VoyahClient повторно используются экспериментом; если свежего снимка нет, запускается обычное чтение OEM-кэша. Отменённые запросы не публикуются в общий снимок.
- Снимки, прочитанные более 6 секунд назад, отсутствующие и некорректные показания становятся недоступными. Это возраст нашего чтения OEM-кэша, а не время измерения автомобильного датчика. Запросы записи и управления явно отклоняются: команды автомобилю в этом эксперименте не отправляются.
- В «Диагностику» добавлены проверка данных климата, просмотр и сохранение журнала Ultra. Журнал ограничен двумя файлами примерно по 2 МБ.
- Существующий стек CarPlay получает необязательное расширение. По умолчанию оно отсутствует; пути iAP2, сертификаты, аудио, видео и root helper не заменяются.
- В release нет реализации эксперимента, CAF/RCS-сервера и его интерфейса. Сохранённый debug-переключатель не активирует эксперимент в release.

Основа протоколов, каталог типов CAF и схема дерева конфигурации: [xcertplay, ветка iAP2-rewrite, e021581](https://github.com/shilapi/xcertplay/tree/e021581f1cdcebc495e5a81aae1bef5154848657). Исходный проект VoyahPlay основан на [DiPlay](https://github.com/shihabal3amri/DiPlay). Интеграция с OEM API Voyah продолжает использовать ранее указанные в README материалы [VoyahTune](https://github.com/nexron171/VoyahTune).

Это протокольный эксперимент: принятие конфигурации iPhone и появление штатного экрана климата Ultra пока не подтверждены. UI Sync, графические ресурсы Ultra, радио и вывод Ultra на приборную панель в этот этап не входят.
