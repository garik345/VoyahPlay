VoyahPlay Ultra 0.1.23 — исправление по присланному DiPlayActivity(1).kt

1. Распакуйте эти файлы в корень проекта VoyahPlay. Рядом должны остаться
   ORIGINAL apply-ultra-pilot.ps1, edits.json, CHANGELOG-0.1.23.md и папка payload
   из исходного пакета Ultra 0.1.23. Замените прежний apply-ultra-pilot-fix.ps1 версией из этого архива.
2. Выполните из корня проекта:
   powershell -NoProfile -ExecutionPolicy Bypass -File .\apply-ultra-pilot-fix.ps1
3. После успешного применения собирайте automotive/debug.

ultra-current-settings/DiPlayActivity.kt — готовый изменённый исходник для
common/src/main/java/com/shilapi/xcertplay/DiPlayActivity.kt. Скрипт передаёт его
исходному установщику, чтобы сохранить предварительную проверку ВСЕХ файлов
и резервную копию. Вручную переносить этот файл перед запуском не требуется.

Что изменено в Activity:
- отдельная секция ULTRA_CLIMATE, отнесённая только к «Дополнительно»;
- переключатель пилота через существующие filteredSection/toggle;
- после изменения появляется существующее предложение переподключить CarPlay;
- три действия Ultra в «Диагностике»: проверить климат, посмотреть и сохранить журнал;
- новые элементы доступны только в debug, через фасад из исходного пакета Ultra.

Проверки: синтаксический разбор Kotlin; четыре точечных изменения с проверкой
сохранности остального исходника; принадлежность секций ровно одной категории;
синтаксис PowerShell по грамматике. Полная сборка APK и запуск в Windows
PowerShell в этой среде не выполнялись.
