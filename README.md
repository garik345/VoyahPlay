# VoyahPlay

CarPlay для **Voyah Free 2026 RU, EREV, Android 11**.
Форк [DiPlay](https://github.com/shihabal3amri/DiPlay), лицензия [AGPL-3.0](LICENSE).

Версия **0.1.24**: `0.2.19-voyahplay.0.1.24`; код версии automotive — `1208`.
Пилот климата: **`opack-5-hvac`**, только debug; меню iPhone пока не подтверждено.
Ревизия настроек: `voyah-settings-20261017-r2`. Root-помощник: **1.1.2**.
Основа этого обновления: `main 7a7cd349d4929017a003a89586a88a629170979b`.

## Что изменилось

- Главное окно и вход из CarPlay открывают **один экран настроек**: категории,
  поиск и темы. Старое отдельное меню CarPlay больше не строится.
- Проверка помощника отдельно показывает доступность, версию, UID и совместимость.
  Ответ старой версии не выдаётся за отсутствие помощника. Изменения автозапуска
  и геометрии требуют совместимый помощник и прежние проверки владельца сокета.
- Отчёт включает версию установленного APK, код версии, UID, ожидаемую и фактическую
  версии помощника, а также исходную ошибку подключения.
- Исправлена обработка проверок, добавленных в уже открытый раздел настроек.
- Скрытие навигационного дока связано с полной шириной через существующую добавку
  Tweaks 1.1; выключение восстанавливает исходные границы.
- Сохранены автомобильные кнопки, порядок и положение снизу/слева/справа/с двух
  сторон, цветовая индикация и уровни. Строка трека ограничена 20 символами.

## Сборка и установка

Основной модуль для этой мультимедиа — **automotive**. Распакуйте изменённые файлы
в корень проекта с заменой, выполните Gradle Sync и выберите debug либо release.

```powershell
.\gradlew.bat :automotive:assembleDebug
adb install -r .\automotive\build\outputs\apk\debug\automotive-debug.apk
```

Устанавливайте поверх существующего приложения с той же подписью. Удаление
приложения меняет UID и требует повторной привязки помощника.
Для release нужна собственная конфигурация подписи.

Аутентификация CarPlay — локально и офлайн. Ключи, сертификаты и сопряжения
не заменяются этим пакетом. Внешний каталог локальных assets можно передать
через `DIPLAY_AUTH_ASSETS_DIR`. Текущие движки CarPlay и их USB/Wi-Fi настройки
сохраняются из GitHub.

## Root-помощник после обновления APK

Помощник запускается отдельно из приватной сохранённой копии APK.
**Установка нового APK эту копию не обновляет.** Помощник привязан к UID приложения.
Права `/system/xbin/su` менять не требуется; прежний инъектор не запускается.

Откройте «Дополнительно → Root-помощник VoyahPlay» и нажмите
«Состояние root-помощника и автозапуска». Если помощник не отвечает, версия
несовместима или UID изменился, после установки APK выполните из этого проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\root-module\root-helper.ps1 -Mode Install
```

Для уже совместимого помощника с прежним UID повторная установка не нужна.
При сохранении проблемы отправьте результат «Скопировать отчёт root-помощника».
После первоначальной установки и включения автозапуска компьютер при обычной
перезагрузке мультимедиа не требуется.

## Настройки и ограничения

Из CarPlay настройки открываются удержанием выбранной автомобильной кнопки
(по умолчанию — подогрев руля). Жест нескольких пальцев и шестерёнка не используются.
Вход в настройки сохраняет соединение; изменения изображения/звука, которым
нужна новая сессия, применяются существующей кнопкой переподключения.

Полная ширина проверяет геометрию основного экрана: `145,45 / 1775×675` ↔
`0,45 / 1920×675` и известный вариант высоты 485. Другие экраны не пересоздаются.
Расширение под верхней OEM-строкой этим методом не реализовано; переключатель
панели состояния отправляет запрос Android, результат зависит от OEM-политики.

### VoyahPlay 0.1.21 — 18.10.2026

- Исправлена передача `audioFocusAutoYield` при создании звукового движка. Для Voyah опция «Mute media on temporary focus loss» всегда выключена; старое сохранённое `true` сбрасывается при создании новой сессии звука.
- Значения по умолчанию в `AndroidMediaSink` и `AudioFocusCoordinator` изменены на `false`, чтобы пропущенный аргумент не включал опцию снова.
- В диагностический журнал добавлено фактическое состояние: `Audio: focus policy enabled=… muteOnTransientLoss=false`.
- Добавлены проверки миграции старого значения и последовательности потеря фокуса → звонок → возврат музыки. Обычное управление Audio focus и ducking не изменены.
- Обновление точечно меняет текущие исходники, сохраняя ранее применённые изменения интерфейса и root-помощника. Само устранение заикания после звонка требует проверки в автомобиле.

### VoyahPlay 0.1.22 — 18.10.2026

- Иконки в левом и правом рядах управления автомобилем уменьшены ещё на 20% относительно текущего размера. Всплывающие кнопки используют тот же масштаб. Нижний ряд, цвета, точки уровня и размеры областей нажатия сохраняются.
- При скрытом левом доке и фактически расширенном окне основного экрана слева зарезервирована полоса 16 dp для штатной ручки шторки. Используется плотность физического экрана, независимо от масштаба интерфейса приложения.
- Полоса применяется к общему контейнеру CarPlay, кнопок, главной страницы и настроек. Видеокадр и обработка касаний используют одну уменьшенную область; всплывающие кнопки остаются внутри неё. При обычной ширине окна, на других дисплеях и в многооконном режиме полоса не добавляется.
- Статус-бар сверху этой правкой не скрывается. Текущий подтверждённый метод Tweaks расширяет только ширину; геометрия основного окна остаётся с y=45 и высотой 675. Android-флаги скрытия верхней строки уже применяются, но на проверенной прошивке этого недостаточно для OEM-панели.
- Добавлен отдельный сборщик отчёта `collect-status-bar.ps1` для сравнения окон VoyahPlay и штатного «Релакс». Скрипт читает диагностику; с `-IncludeApks` копирует APK системных компонентов для изучения.

### CarPlay Ultra: климат и комфорт — 0.1.24, opack-5-hvac

- Исправлены прямой OPACK, заголовки asyn/cmnd, транспортные ответы sync/rply и pluginID 0.
  Старый bplist-носитель принимается отдельно для каждого канала. Исходный iAP-туннель сохранён.
- `/info` теперь строится через экземпляр протокола активной сессии, получающий свежие значения OEM.
  Раньше он использовал общий прототип, а чтения поступали другому экземпляру.
- В описание добавлены реальные displayPanels, две температурные зоны, VehicleLayoutKey,
  Cabin, вентилятор, AUTO, рециркуляция, обдув стёкол и ресурсы 5Seater.
- Подтверждены по присланным OEM-файлам H97C: температуры водителя/пассажира, питание климата,
  A/C, AUTO, вентилятор, рециркуляция, переднее и заднее стекло. Импульсные команды отличаются
  от абсолютных: перед импульсом читается состояние, после него требуется подтверждение.
- Сохранены команды подогрева и вентиляции обоих сидений и подогрева руля через CAF.
  Выключенный переключатель имеет уровень 0 независимо от сохранённой мощности. Неизвестное
  состояние не подменяется выключенным. Ошибка/тайм-аут не превращаются в успех записи.
- Все команды требуют существующего WRITE_CANBUS и совпадения проверенного CAN APK.
  При чтении, подписке и подключении команды машине не отправляются. MAX A/C, радио и
  датчик температуры салона не заявляются как работающие возможности этого этапа.
- Настройка в «Дополнительно» называется «Климат и комфорт через CarPlay Ultra».
  По умолчанию выключена, применяется с нового подключения. Переводы обновлены во всех 8 локалях.
  Диагностика выводит `WIRE_REV=opack-5-hvac`, HVAC-поля и результаты обратного чтения.
- Появление климатического интерфейса на iPhone **ещё не подтверждено**. Прежние подписки
  и updateNotify подтверждали протокольный обмен. Новый пакет исправляет найденные расхождения,
  но не выдаёт это за результат испытания на машине.
