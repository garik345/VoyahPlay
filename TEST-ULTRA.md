# Проверка VoyahPlay 0.1.24 — opack-5-hvac

Это обновление уже установленного пилота, включая ранние транспортные исправления и управление
подогревами/вентиляцией/рулём. Проверено относительно GitHub `main 7a7cd349d4929017a003a89586a88a629170979b`.
Появление штатного климатического меню CarPlay пока не подтверждено. Подписка и отправка значений
в прежнем отчёте этого не доказывали. Исправления ниже устраняют найденные расхождения протокола.

1. Сохраните собственные изменения в Git. Распакуйте архив в корень проекта рядом с `gradlew.bat`
   с заменой файлов и сохранением путей `common`, `shared`, `payload`, `Docs`.
   Дополнительный установщик для этого пакета не нужен. Старые `apply-ultra-pilot*.ps1` повторно
   не запускайте: это установщики первоначального этапа 0.1.23, они не обновляют уже изменённые исходники.
2. Выполните Gradle Sync. Выберите **automotive / debug**, соберите и установите APK поверх
   приложения с прежней подписью. Версия этого обновления — `0.2.19-voyahplay.0.1.24`, code 1208.
   Release не содержит экспериментальной реализации. Сертификаты, сопряжение и root helper не переустанавливаются.
3. На стоянке откройте **Диагностика → Ultra: проверить данные климата**. Установите штатным
   климатом разные температуры слева и справа, измените вентилятор, A/C и AUTO. Сохранённый журнал
   должен показывать соответствующие поля `hvac=`. Ошибка чтения не считается состоянием «выкл».
4. В **Дополнительно** включите **«Климат и комфорт через CarPlay Ultra»**.
   Примените настройку с полным переподключением CarPlay. Простой переход между окнами не создаёт новую сессию.
5. В отчёте нового подключения найдите `WIRE_REV=opack-5-hvac`. Старые строки bad magic в истории
   относятся к прежним версиям; проверяйте участок после новой записи RECEIVER CONFIG.
6. Проверьте сам экран CarPlay: появились ли температурные элементы в доке, приложение/экран климата.
   Зафиксируйте результат. Появление пунктов iPhone зависит от принятия всей конфигурации телефоном;
   запись INFO или updateNotify сама по себе не подтверждает отображение.
7. Если элементы появились, измените температуру водителя на 0.5 °C, затем отдельно пассажира.
   Проверьте штатный климат автомобиля. После этого проверяйте вентилятор и остальные функции
   по одной, сверяя с OEM-экраном. Для выключения импульсной функции приложение сначала проверяет состояние.
8. Сохраните **Диагностика → Ultra: сохранить журнал** и пришлите `voyahplay-ultra-*.txt`
   вместе с результатом появления/отсутствия меню. Если интерфейс по-прежнему отсутствует,
   нужен именно журнал новой сессии opack-5-hvac; повторно снимать присланные APK/JAR не требуется.

В новом отчёте важны:

| Строка | Проверка |
| --- | --- |
| RECEIVER CONFIG / WIRE_REV=opack-5-hvac | Запущен этот пилот, а не предыдущий APK |
| NEGOTIATED VSP=1 | iPhone согласовал VSP |
| VEHICLE … hvac=… | Есть реальные значения обеих зон и HVAC |
| INFO … panels=1 … sample=… | Описание экрана и значения сессии попали в /info |
| CAF CONFIG … hvac=… | iPhone запросил новую конфигурацию; список доступных записей |
| CAF RX … registerRequest | Телефон подписался на указанные IID |
| OEM WRITE request / result confirmed=true | Запрос iPhone совпал с обратным чтением автомобиля |
| errors … -50 / -6727 | Параметр отвергнут / выполнение не подтверждено |

Если при INFO `sample=null`, а позднее появились VEHICLE-данные, сообщите это отдельно.
Если `hvac=` пуст, команды не заявлены из-за отсутствующего WRITE_CANBUS; рабочая подписка
не является доказательством этого разрешения. Не выдавайте разрешение вслепую: пришлите отчёт.

Выключение эксперимента с переподключением возвращает обычное описание CarPlay.
Полноэкранный режим, док дополнительных кнопок, звук и USB/Wi-Fi этим обновлением не настраиваются.
