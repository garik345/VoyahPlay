## Установка двойным щелчком в Windows

[Готовый ZIP с ADB и установщиком](../../build/pi-dock72-20261028/release-final/helper/VoyahPlay-root-helper-1.2.9-with-ADB.zip).
Сначала установите актуальный VoyahPlay на автомобиль. Распакуйте весь ZIP,
подключите мультимедиа по ADB и запустите **INSTALL.cmd**. При нескольких
устройствах выберите автомобиль по номеру; при одном serial определяется сам.
Установщик берёт помощник из установленного APK и затем проверяет состояние.
Исходники проекта, Java и Android Studio для этого запуска не нужны.

Если предложена перезагрузка, перезагрузите мультимедиа обычным способом,
затем запустите **STATUS.cmd**. Окно остаётся открытым до нажатия клавиши.
Журнал запуска сохраняется в `logs/`, подробные отчёты — в
`build/voyah-root-helper/` внутри распакованной папки.
Существующий root и совместимые Tweaks/injector на автомобиле нужны заранее.

Повторная сборка ZIP из локальных исходников:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\root-module\build-portable.ps1 `
  -AdbDirectory 'C:\Tools\platform-tools' -OutputDirectory '.\build\root-helper-portable-new'
```

`build-portable.ps1` копирует только ADB, две DLL, NOTICE, метаданные и установщик.
Android APK, исходники автомобиля и ключи ADB не входят в комплект.

## Запуск из исходников

Очистка исходников требуется только при переходе со старого ZIP с legacy-модулем:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\root-module\remove-legacy-sources.ps1
```

Соберите и установите `automotive`, затем:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\root-module\root-helper.ps1 -Mode Install
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\root-module\root-helper.ps1 -Mode Status
```

Команды выше рассчитаны на одно устройство и доступный через `PATH` ADB.
Если `adb devices -l` показывает больше одного устройства, добавьте `-Serial SERIAL`
к обеим командам, взяв идентификатор нужной мультимедиа из первого столбца списка.
Для одного устройства `-Serial` не требуется.

`adb.exe` не входит в Windows. В готовом ZIP он уже есть; при запуске скрипта
непосредственно из исходников ADB нужно подготовить отдельно, скрипт его не скачивает.
Если ADB отсутствует, [установите Android SDK Platform-Tools](../../docs/INSTALL_NEW_CAR.md#подготовить-adb-в-windows).
Если файл уже есть, но не добавлен в `PATH`, передавайте его полный путь:
`-Adb 'C:\Tools\platform-tools\adb.exe'`. Проверка списка без `PATH`:
`& 'C:\Tools\platform-tools\adb.exe' devices -l`.

В приложении доступны полная ширина через Tweaks, расширение вверх и автозапуск помощника.
В opack-49/helper 1.2.2 добавлен выключенный по умолчанию переключатель
«Названия станций в штатном радио (экспериментально)». Для него нужен проверенный
APK `com.pateo.rdsapp` и имеющийся совместимый injector. При переходе с 1.2.1
повторите `Install` после установки нового APK. Прежний helper остаётся совместимым
с полным экраном. [Совместимость и откат патча радио](../../docs/oem-radio-labels-20261026.md).
Старый модуль больше не устанавливается и не запускается.

Порядок проверки, backup/восстановление и все режимы скрипта:
[../../docs/VOYAH_ROOT_HELPER.md](../../docs/VOYAH_ROOT_HELPER.md).

`collect-diagnostics.ps1` сохранён как архивный сборщик предыдущего исследования;
для текущего помощника используйте `-Mode Status` и отчёт из меню.
