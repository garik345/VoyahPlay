VOYAHPLAY __APK_REVISION__ / ROOT HELPER 1.2.16 — УСТАНОВКА НА ДРУГОЙ АВТОМОБИЛЬ

Установщик 1.0.3 включает автозапуск root-helper после установки.
Opack-108 включает подготовку области карты до начала маршрута, память источника
радио/CarPlay, паузу радио при открытии водительской двери и дополнительное
приглушение радио на время Siri с возвратом уровня после ответа.

Необязательный обработчик радио не участвует в остановке helper,
когда нет радио и состояния его агента. Выключенный обработчик без агента не запускается.
В известных ПИ без приёмника APK также отключает радио и скрывает его настройки.
Для обновления старого helper используется новый проверенный сценарий остановки;
файлы старого снимка остаются на месте до успешного завершения остановки.
При реально существующем радио сохраняются безопасная остановка, повторы BUSY и диагностика.

1. Припаркуйте автомобиль. Завершите звонки и закройте CarPlay.
2. Распакуйте ВЕСЬ ZIP в обычную папку Windows. Не запускайте из архива.
3. Подключите мультимедиа по ADB и подтвердите отладку. Нужен уже работающий su 0.
4. Запустите INSTALL.cmd двойным щелчком. ADB уже включён, Android Studio и Java не нужны.
   Одно устройство выбирается автоматически. При нескольких выберите номер автомобиля.
   Serial вручную нужен только при нескольких устройствах; его можно передать параметром
   powershell -ExecutionPolicy Bypass -File .\start-full-install.ps1 -Serial НОМЕР
5. Если Tweaks отсутствует, установщик поставит включённый VoyahTweaks.apk и откроет его.
   Выполните штатную активацию/подготовку системы в Tweaks. Затем повторите INSTALL.cmd.
   Если Tweaks уже установлен, его APK не заменяется. Лицензия/подписка не изменяется.
6. Установщик проверит прошивку, исходные компоненты и резервную копию моста, обновит
   VoyahPlay, добавит мост Tweaks 1.1 и установит root-helper из этой же APK с правильным UID и автозапуском.
7. Перезагрузите мультимедиа обычным способом. Автоматической перезагрузки нет.
8. Восстановите ADB и запустите STATUS.cmd. Если мост ещё не готов, дождитесь загрузки Tweaks.
9. В VoyahPlay настройте подключение iPhone. В «Дополнительно» включите CarPlay Ultra,
   радио (если в машине есть приёмник) и карту на приборке по желанию. Настройку размера
   карты можно менять отдельно. Изменения этих функций требуют следующего подключения iPhone.
10. В «Экран» включите скрытие дока/статус-бара. Эти настройки доступны только при готовности
    всех обработчиков расширения окна. Ultra требует проверенного helper; карта дополнительно
    требует совместимую приборку, работающий мост и открытую медиакарточку.

ПОДДЕРЖИВАЕМЫЕ ПОЛНЫМ УСТАНОВЩИКОМ ПРОШИВКИ
Android 11: проверенная RU H97, ПИ OTA7.0 build86 и ПИ OTA7.2 build35.
Решение принимается по точной паре SHA-256 services.jar и SystemUI, затем проверяются
injector и модуль Tweaks. Название/номер версии на экране сами по себе недостаточны.
На неизвестной прошивке установка останавливается до изменений. Запустите COLLECT.cmd
и передайте НОВЫЙ архив отчёта с рабочего стола для добавления поддержки.

СОСТАВ
VoyahPlay.apk (automotive/debug с локальной офлайн-аутентификацией), root-helper 1.2.16
внутри APK, мост Tweaks 1.1, Windows ADB с DLL и лицензией, установщик и сборщик.
prerequisites содержит исходные проверенные VoyahTweaks.apk, frida-inject и QGWindowPolicy.apk.
VoyahTweaks.apk устанавливается только при отсутствии Tweaks. Остальные два файла —
сопутствующие компоненты штатной подготовки Tweaks, не замена произвольных системных файлов.
При их отсутствии/несовпадении закончите штатную подготовку Tweaks и повторите установку.
Установщик не копирует init.logcat.sh, services.jar, SystemUI, CAN/cluster APK или QGAPI.jar
с другой машины. На каждой машине сохраняются её родные файлы; именно их проверяет APK.
Сопряжения iPhone, настройки, UID и данные активации первой машины в комплект не входят.

ПРОВЕРКА
После установки проверьте: обычный CarPlay и звук; климат/автомобиль Ultra; полный экран
без мигания дока при громкости/климате; маршрут и карту на приборке без Retry.
Диагностика helper и границ окна перенесена в «Диагностика». Ручные тесты MEDIA/NAVI/AR
убраны из «Дополнительно». При ошибке сохраните logs и результат COLLECT.cmd.
При несовпадении подписи APK установщик не удаляет старое приложение и не стирает данные.

ОТКАТ МОСТА
RESTORE_BRIDGE.cmd возвращает только сохранённый оригинальный ss11.bin этой машины.
Затем перезагрузите мультимедиа. Полный экран и карта станут недоступны; APK и helper
не удаляются. Резервная копия: /data/local/voyahplay-tweaks-bounds-test/ss11.bin.original.

FILES-SHA256.json содержит контрольные суммы поставки. Не переносите каталоги данных
приложений и root-helper между автомобилями. Root этот комплект не получает.
